# ショートステイ 持ち物確認

短期入所（ショートステイ）の**入所時と退所時で、お預かりした持ち物の数量が合っているか**を
確認するためのツールです。社会福祉法人・医療法人・介護施設での利用を想定しています。

ブラウザを開くだけで使えます。インストールは不要で、Windows・Mac のどちらでも動きます。

## なぜ数量照合なのか

多くの施設の短期入所業務マニュアルでは、退所時に「入所時チェック表に基づき、
入退所時の数量に増減がない旨をご家族に説明して荷物をお渡しする」と定められています。
衣類の紛失が起きれば、管理者を交えた協議や弁償の話にもなります。

紙の様式ではこの照合が目視と手計算に頼るため、このツールでは**照合を自動化**しました。

## 楽になる3点

1. **衣類の必要数の自動計算**
   利用開始日・終了日を入れると泊数を計算し、「1泊分 × 泊数」の目安数を各行に表示します。
   5泊以上は5着で頭打ちにする、という一般的な運用に合わせています。

2. **内服薬の必要包数の自動計算**
   服用のタイミング（朝・昼・夕・寝る前）を選ぶと、`回数 × 利用日数` の必要包数を表示します。
   入所時に「日数分の内服が揃っているか」を数える作業に対応します。

3. **入所⇔退所の数量照合**
   同じ行に来園時と帰園時の数量を入れると、一致＝緑、不一致＝赤で即座に色分けされます。
   画面下部に「差異◯件：品目名」が常に表示されるので、退所時の説明がそのまま行えます。

## 主な機能

- 品目は6分類（衣類等／洗面・整容道具等／薬／貴重品／その他／来園時の服）
- 追加候補ボタンで、保険証・杖・車椅子・タオルケット等をワンタップ追加
- 任意の品目を自由に追加・削除できます
- 備考欄は「上・下」「ケース有・無」「本人管理・施設管理」などを候補から選択できます
- **繰り返し利用される方は、前回の持ち物構成を自動で引き継ぎます**（新規作成時に同じ氏名を入力）
- 写真記録（任意）。入所時・退所時の荷物を撮って残せます
- 印刷するとA4縦1枚、紙の様式に近い2段組で出力されます。差異のある行は網掛けになります
- バックアップの書き出し・取り込み（JSON）

## 使い方

1. 「新規作成」→ 利用者氏名を入力
2. 事業所・利用期間・確認者を入力
3. **入所時**：各品目の「来園」欄に数量を入力 →「印刷」して控えを保管
4. **退所時**：記録一覧から同じ記録を開き、「帰園」欄に数量を入力
5. 画面下部の判定を確認し、差異がなければご家族へ説明。「印刷」して確認表として保管

## 個人情報の取扱い

- **入力内容も写真も、外部に送信されません。** すべてお使いのパソコンのブラウザ内で処理されます。
- 記録はブラウザの保存領域に保存されます（記録は localStorage、写真は IndexedDB）。
  **パソコンやブラウザを変えると引き継がれません。** また、ブラウザの
  「閲覧履歴・サイトデータの削除」を行うと記録も消えます。
  「バックアップ」から定期的に書き出して保管してください。
- 利用者のお名前を扱うため、操作するパソコンは施設内の管理された端末に限定し、
  書き出したバックアップファイルもあわせて厳重に管理してください。

## 限界（必ずお読みください）

このツールは職員による現物確認を**置き換えるものではありません**。
数え間違い・記入漏れを減らすための補助としてお使いください。

- 数量を入力するのは職員です。入力そのものが誤っていれば照合も誤ります
- 写真は記録として残すだけで、写っている物の判別や個数の自動カウントは行いません
- 最終判断は必ず職員が行ってください

## 技術構成

- HTML1ファイルのみ。外部ライブラリ・サーバー処理・外部API呼び出しは一切ありません
- 保存先はブラウザ内（localStorage / IndexedDB）
